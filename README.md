# Book Store MVC

## Features
- Add and remove books and authors
- Display books with author names and prices
- Confirm book removal
- Use shared and page-specific layouts

## Technologies
C#, ASP.NET Core MVC, Razor, Bootstrap, and JavaScript.

## Run
Open BookStoreHW5.sln in Visual Studio 2022 and run the project.

Data is stored in memory and resets when the application restarts.
